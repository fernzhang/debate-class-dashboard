# Debate Arena

A Streamlit dashboard for debate class homework, POI participation, class points, and teacher feedback.

## Files

- `app.py`
- `sample_students.csv`
- `requirements.txt`
- `README.md`

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## CSV columns

`Date, Student, Homework_Status, Homework_Points, POI_Points, Class_Points, Bonus_Points, Feedback`

Each row represents one student on one class date.
